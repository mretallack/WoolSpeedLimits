# Reproducing the Wool Simulation Results

Every headline number in `EXPERIMENT_REPORT.md` is reproducible from this
repository. This document gives the exact steps and lists what is committed
versus what is regenerated.

## Reproducibility guarantees

- The four comparison configs set a **fixed seed** (`<seed value="42"/>`):
  `wool.dft_now.sumo.cfg`, `wool.dft_20mph.sumo.cfg`,
  `wool.dft_offpeak_now.sumo.cfg`, `wool.dft_offpeak_20mph.sumo.cfg`.
  Re-running therefore yields **identical** results (only the `generated on …`
  timestamp comment differs).
- Demand is survey-calibrated; see `FLOW_CALIBRATION.md`.
- The 20mph network matches the Dorset Council consultation; see
  `sumo/NETWORK_BUILD.md` and `sumo/build_20mph_net.py`.

## What is committed (directly checkable)

| File | Contains | Feeds |
|---|---|---|
| `wool.dft_<scenario>.statistic.xml` | aggregated run stats | journey time, time loss, waiting (§2.2) |
| `wool.dft_<scenario>.tripinfo.xml` | per-vehicle trips | durations, route lengths |
| `wool.dft_<scenario>.road_emissions.xml` | road-level emissions (edgeData) | **road_total** column (§2.1) |
| `wool.dft_<scenario>.traffic_stats.xml` | lane traffic stats | flows, queues |
| `wool.dft_<scenario>.vehicle_emissions.csv` | **per-vehicle summary** (one row per vehicle: trip totals, route length, mean noise) | **vehicle_total** and **vehicle_perkm** columns (§2.1), noise (§3.3) |
| `results_peak.csv`, `results_offpeak.csv` | the summary % tables | report §2.1 |

The per-vehicle **summary CSV** was added so the vehicle-level results can be
checked without the multi-hundred-MB `--emission-output` files (which stay
git-ignored; see below).

## Regenerating the raw results

```bash
cd sumo

# 1. Run the four scenarios (writes statistic/tripinfo/road_emissions/
#    traffic_stats and the large vehicle-level *.emissions.xml).
sumo -c wool.dft_now.sumo.cfg
sumo -c wool.dft_20mph.sumo.cfg
sumo -c wool.dft_offpeak_now.sumo.cfg
sumo -c wool.dft_offpeak_20mph.sumo.cfg

# 2. Compact per-vehicle CSVs from the large emission output.
for t in dft_now dft_20mph dft_offpeak_now dft_offpeak_20mph; do
  python3 summarize_vehicle_emissions.py \
    --emissions wool.$t.emissions.xml --tripinfo wool.$t.tripinfo.xml \
    --out wool.$t.vehicle_emissions.csv
done

# 3. Re-derive the summary tables.
python3 analyze_emissions.py \
  --now-edge wool.dft_now.road_emissions.xml \
  --now-veh  wool.dft_now.emissions.xml --now-trip wool.dft_now.tripinfo.xml \
  --scheme-edge wool.dft_20mph.road_emissions.xml \
  --scheme-veh  wool.dft_20mph.emissions.xml --scheme-trip wool.dft_20mph.tripinfo.xml \
  --label-now "peak 30mph" --label-scheme "peak 20mph" --csv results_peak.csv

python3 analyze_emissions.py \
  --now-edge wool.dft_offpeak_now.road_emissions.xml \
  --now-veh  wool.dft_offpeak_now.emissions.xml --now-trip wool.dft_offpeak_now.tripinfo.xml \
  --scheme-edge wool.dft_offpeak_20mph.road_emissions.xml \
  --scheme-veh  wool.dft_offpeak_20mph.emissions.xml --scheme-trip wool.dft_offpeak_20mph.tripinfo.xml \
  --label-now "offpeak 30mph" --label-scheme "offpeak 20mph" --csv results_offpeak.csv

# 4. Noise (§3.3).
python3 analyze_noise.py --now wool.dft_now.emissions.xml \
                         --scheme wool.dft_20mph.emissions.xml
python3 analyze_noise.py --now wool.dft_offpeak_now.emissions.xml \
                         --scheme wool.dft_offpeak_20mph.emissions.xml
```

## Ignored large files

`wool.dft_*.emissions.xml` (per-vehicle per-timestep; 100–360 MB each, ~940 MB
total) are git-ignored — see `sumo/.gitignore`. They are fully regenerated by
step 1 above. Their content is captured in compact form by the
`*.vehicle_emissions.csv` summaries.

## Checking a value by hand

- **road_total** for a metric = sum of `<edge ... METRIC_abs="…">` over all
  edges and intervals in `wool.dft_<scenario>.road_emissions.xml`.
- **vehicle_total** = sum of `METRIC_abs` column in
  `wool.dft_<scenario>.vehicle_emissions.csv`.
- **vehicle_perkm** = vehicle_total ÷ sum of `route_length_km` in the same CSV.
- **noise** = mean of the `noise_mean_dBA` column (or the raw `noise` attribute).
